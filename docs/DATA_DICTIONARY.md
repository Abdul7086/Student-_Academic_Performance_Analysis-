# Data Dictionary

| Column | Description |
|---|---|
| `Student_ID` | Unique student record identifier |
| `Student_Name` | Student name as supplied in the dataset |
| `Gender` | Gender category in the source data |
| `Class` | Class section (`10A`, `10B`, or `10C`) |
| `Attendance_Percentage` | Attendance percentage |
| `Maths_Marks` | Mathematics marks |
| `Science_Marks` | Science marks |
| `English_Marks` | English marks |
| `Social_Studies_Marks` | Social Studies marks |
| `Computer_Marks` | Computer marks |
| `Total_Marks` | Sum of the five subject marks (maximum 500) |
| `Average_Marks` | Mean of the five subject marks (maximum 100) |
| `Grade` | Grade category in the source data |
| `Result` | Pass/fail result category in the source data |

The included CSV has 100 rows and 14 columns. Values and category labels are retained as supplied.
